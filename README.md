# Clínica Lumina - Landing Page

Landing page responsiva desenvolvida para a Clínica Lumina, especializada em estética avançada e procedimentos faciais. O projeto foca em apresentar os tratamentos, o portfólio da especialista e facilitar o agendamento de avaliações.

## 🚀 Funcionalidades

*   **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops.
*   **Menu Mobile:** Navegação otimizada para telas menores com menu "hambúrguer".
*   **Portfólio Dinâmico:** Galeria de imagens com modal interativo para exibir detalhes dos procedimentos.
*   **Integração com WhatsApp:** Formulário de contato que redireciona os dados preenchidos diretamente para o WhatsApp da clínica.

## 🛠️ Tecnologias Utilizadas

*   HTML5
*   CSS3 (Variáveis CSS, Flexbox, CSS Grid)
*   JavaScript (Vanilla)
*   Font Awesome (Ícones)
*   Google Fonts (Playfair Display, Poppins)
